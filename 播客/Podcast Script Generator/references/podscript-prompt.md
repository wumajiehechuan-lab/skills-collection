<guidelines>

1. **为 N 位说话者建立独特且一致的角色形象：**
   
   * **基于 `num_speakers` 创建角色：** 为指定的说话者数量，为每位创建独特且一致的角色形象。
   * **说话者 0（主导主持人/协调者）：** 此说话者应始终作为主要主持人。他们引导对话、介绍环节、提出关键问题，并帮助总结要点。他们的语调是引导性和吸引人的。
   * **其他说话者（联合主持人）：** 对于 `speaker_1`、`speaker_2` 等，创建能增强讨论的互补角色。角色示例包括：
     * **专家：** 从源内容中提供深入的事实见解。
     * **好奇的新手：** 提出听众可能有的澄清性问题，充当听众代表。
     * **实用怀疑论者：** 通过质疑假设或关注现实影响来使对话接地气。
     * **热情者：** 带来活力，分享个人轶事，并对主题表达兴奋。
   * **一致性是关键：** 确保每位说话者在整个脚本中保持其独特的声音、词汇和观点。他们的互动应感觉像是真实的、已建立的群体动态。
   
2. **遵循指定的发言模式：**
   
   * **如果 `turn_pattern` 为 "sequential"：** 说话者应按固定、重复的顺序发言（例如：0 -> 1 -> 2 -> 0 -> 1 -> 2...）。在整个脚本中保持此严格序列。
   * **如果 `turn_pattern` 为 "random"：** 发言顺序应更动态、更不可预测，模仿真实的群体对话。一位说话者可能连续进行两次简短发言以详细说明，另一位可能插话，或者一位提问而由不同的说话者回答。确保在整个播客中**平衡分配**发言时间，避免任何单一说话者主导或被冷落太久。
   
3. **创作自然且动态的群体对话：**
   
   * **模仿真实对话：** 使用缩略语（如"不"、"它是"）、感叹词（"哦！"、"哇！"、"嗯"）和话语标记（"你知道"、"对吧？"、"好吧"）。使用常见的语气词和停顿词。
   * **促进群体互动：** 编写说话者真正相互回应的对话。他们应建立在*任何*其他说话者提出的观点上（"没错，而且补充一下 [说话者 X] 说的..."），向群体提出后续问题，尊重地表达同意/不同意，并表现出积极倾听。对话不应是与主持人的一系列 1 对 1，而是真实的群体讨论。
   * **变化节奏与速度：** 混合简短有力的台词和更长、更具解释性的台词。节奏应感觉自发且协作。
   
4. **为流畅性和听众参与度构建结构：**
   
   * **自然开头：** 以自然流畅的对话开始，仿佛介绍刚刚结束。
   * **逻辑推进与路标：** 主导主持人（`speaker_0`）应平滑引导听众通过信息，使用清晰的过渡连接不同观点。
   * **有意义的结论：** 通过总结群体讨论的关键要点结束，强化核心信息。以最终思考或留给听众的悬念问题结束。
   
5. **无缝且准确地整合源内容：**
   
   * **翻译而非背诵：** 将 `<source_content>` 中的信息重述为适合每位主持人角色的对话语言。
   * **解释与情境化：** 使用类比、示例和说话者间的澄清性问题来分解复杂观点。
   * **自然编织信息：** 将源内容中的事实和数据编织到群体对话中，而不是作为独立的、未消化的块。
   
6. **长度与节奏：**

   * **目标时长与字数：** 创建一个大约 {{usetime}} 音频的转录稿，默认语言为 {{outlang}}。使用以下字数指南：
     * "5 分钟以内"：对于英语，目标为 800-1000 词；对于中文和日语，目标为 800-1500 个中文字符或日文字符
     * "8-15 分钟"：对于英语，目标为 1500-3500 词；对于中文和日语，目标为 3000-6000 个中文字符或日文字符

   * **内容覆盖要求：** 主要目标是确保 `<source_content>` 中的**每个独特主题、关键事实或主要观点**都在最终转录稿中被提及或引用。不应完全遗漏任何主要信息点。
   
   * **优先级策略：** 虽然必须覆盖所有主题，但必须根据重要性分配发言时间和讨论深度。 
     * **关键主题：** 为源材料中最核心和最重要的观点投入更多对话、示例和多主持人的分析。这些应构成对话的核心。
     * **次要主题：** 较不关键的信息或次要细节应更简洁地处理。它们可以由"专家"主持人作为快速事实介绍，由协调者用作过渡陈述，或简要承认而不进行广泛讨论。这确保它们被包含而不打断流程或消耗不成比例的时间。

7. **对话深化与扩展技巧：**

    *   **为了达到准则 6 中定义的强制字数或字符数目标，你必须积极应用以下技巧来扩展和深化对话。严格避免过早结束话题：**
        *   **后续与澄清：** 在提出每个观点后，其他主持人**必须**提出后续问题。例如："你能举个现实例子吗？"或"这对普通人意味着什么？"
        *   **示例与类比：** 对于核心概念，"专家"角色**必须**使用丰富的示例或生动的类比来解释它们。
        *   **发散与联想：** 主持人可以引导对话进行适度的发散。例如："说到这个，让我想起..."或"我们可能会在这个领域看到什么样的未来发展？"
        *   **辩论与对比观点：** 使用主持人角色从不同视角创建讨论，迫使其他主持人提供更详细的辩护和解释。
        *   **重述与总结：** 主持人（`speaker_0`）应在讨论间隙和主题结束时提供重述和总结。
