# 布局速查

本文件收录两种风格的全部布局类型，供 ppt-preflight 在叙事弧规划阶段使用。仅包含布局名称、用途和适用场景，不含 HTML 代码（代码由 guizang-ppt-skill 的 template 负责）。

---

## 风格 A · 电子杂志风（10 种布局）

| # | 布局 | 用途 | 适合内容 |
|---|------|------|---------|
| 1 | 开场封面 | 第 1 页，标题 + 副标题 + 作者信息 | 任何 deck 的封面 |
| 2 | 章节幕封 | 每幕开场，极简（kicker + 大标题 + 一行引语） | 章节分隔、节奏呼吸 |
| 3 | 数据大字报 | 抛硬数据，3×2 或 4×2 网格 | KPI 展示、关键数字 |
| 4 | 左文右图 | 左列标题+正文+callout，右列大图 | 身份反差、故事叙述、产品对比 |
| 5 | 图片网格 | 多图对比，统一高度裁切 | 截图实证、多案例展示 |
| 6 | 两列流水线 | 工作流程，步骤编号+标题+描述 | 方法论、操作流程 |
| 7 | 悬念收束/问题页 | 幕末或收尾，抛出一个问题 | 转折点、引发思考 |
| 8 | 大引用页 | 衬线金句，一句 takeaway | 金句收尾、核心观点 |
| 9 | 并列对比 | Before/After 对照 | 旧模式 vs 新模式 |
| 10 | 图文混排 | 信息密集的图文页，大图+侧边文字 | 产品介绍、案例深挖 |

### 风格 A 布局选择建议

| 叙事弧阶段 | 推荐布局 |
|---|---|
| 钩子（Hook） | 1 开场封面 或 3 数据大字报 |
| 定调（Context） | 4 左文右图 或 10 图文混排 |
| 主体（Core） | 3/4/5/6/9/10 穿插使用 |
| 转折（Shift） | 7 悬念收束 或 8 大引用 |
| 收束（Takeaway） | 8 大引用 或 7 悬念收束 |

## 风格 B · 瑞士国际主义风（22 种版式）

| 编号 | 布局 | 用途 | 适合内容 |
|------|------|------|---------|
| S01 | Index Cover | 封面页，IKB 满屏 + ASCII 呼吸场 | 任何 deck 的封面 |
| S02 | Vertical Timeline + KPI | 演化对比/年代变迁 | 时间线、版本演进 |
| S03 | Split Statement | 核心论点，左右分屏 | 核心观点、对比陈述 |
| S04 | Six Cells | 6 项概念定义 | 概念解释、特性罗列 |
| S05 | Three Layers | 三层架构 | 技术架构、分层设计 |
| S06 | KPI Tower | 4 项数据视觉化高度差 | KPI 对比、数据排名 |
| S07 | H-Bar Chart | 5-10 项排名比较 | 横向排名、性能对比 |
| S08 | Duo Compare | Before/After 对照 | 新旧对比、方案对比 |
| S09 | Dot Matrix Statement | 大引述/statement | 金句、核心宣言 |
| S10 | Split Closing | 收束页 | 结尾页 |
| S11 | Horizontal Timeline | 4-7 步流程 | 路线图、操作步骤 |
| S12 | Manifesto + Ink Banner | 阶段性结论 | 章节总结、宣言 |
| S13 | Three Forces | 3 个对等概念深化 | 三要素分析 |
| S14 | Loop Form | 自学闭环/自动化 | 循环流程、反馈机制 |
| S15 | Matrix + Hero Stat | 8-12 项矩阵 + 总数据 | 矩阵分析、多维度对比 |
| S16 | Multi-card Brief | 6 项快讯小卡 | 信息简报、特性速览 |
| S17 | System Diagram | 三层架构/生态地图 | 系统架构、生态关系 |
| S18 | Why Now | 三论点 + 数据支撑 | 时机论证 |
| S19 | Four Cards | 4 项等权特性 | 特性展示、能力介绍 |
| S20 | Stacked KPI Ledger | 纵向账单数据 | 财务数据、指标明细 |
| S21 | Tech Spec Sheet | 产品规格/benchmark | 技术规格、性能参数 |
| S22 | Image Hero | 21:9 顶图 + 标题块 + 三列 KPI | 产品主视觉、案例展示 |

### 风格 B 版式分类

| 类型 | 版式 | 使用边界 |
|---|---|---|
| 通用 | S01, S03, S08, S09, S10, S11, S19 | 大多数叙事 deck 都能用 |
| 条件通用 | S04, S05, S13, S16 | 取决于数量是否刚好匹配（3/4/6 项） |
| 数据专用 | S02, S06, S07, S18, S20, S21, S22 | 必须有真实时间、数值、指标或案例数据 |
| 结构专用 | S14, S15, S17 | 必须有闭环、矩阵、层级/生态关系 |

### 风格 B 布局选择建议

| 叙事弧阶段 | 推荐版式 |
|---|---|
| 钩子（Hook） | S01 封面 或 S06 KPI Tower |
| 定调（Context） | S03 Split Statement 或 S18 Why Now |
| 主体（Core） | S04/S05/S07/S11/S13/S19 穿插 |
| 转折（Shift） | S09 Dot Matrix 或 S12 Manifesto |
| 收束（Takeaway） | S10 Split Closing 或 S09 Dot Matrix |

### 风格 B 版式多样性硬规则

- 7-8 页 deck 至少使用 6 个不同 S 编号版式
- 10 页以上至少使用 8 个不同版式
- 不允许连续 3 页使用同一种主体结构
- 必须覆盖：封面、收尾、至少 1 个对比/时间线、至少 1 个结构图、至少 1 个图片版式
