# 主题色速查

本文件收录两种风格的全部主题色预设，供 ppt-preflight 在需求澄清阶段使用。仅包含名称、调性和推荐场景，不含 CSS 色值（色值由 guizang-ppt-skill 的 template 负责）。

---

## 风格 A · 电子杂志风（5 套）

| # | 主题 | 调性 | 适合 |
|---|------|------|------|
| 1 | 墨水经典 | 纯墨黑 + 暖米白，杂志感最强 | 通用/商业发布，默认选择 |
| 2 | 靛蓝瓷 | 深靛蓝 + 瓷白，冷静理性 | 科技/研究/数据/技术发布会 |
| 3 | 森林墨 | 深森林绿 + 象牙，沉稳有呼吸感 | 自然/可持续/文化/非虚构 |
| 4 | 牛皮纸 | 深棕 + 暖米，温暖有年代感 | 怀旧/人文/文学/独立杂志 |
| 5 | 沙丘 | 炭灰 + 沙色，克制高级 | 艺术/设计/创意/画廊 |

### 风格 A 推荐速查

| 如果是... | 推荐主题 |
|---|---|
| 不知道选啥 / 第一次用 | 墨水经典 |
| AI / 技术 / 产品发布 | 靛蓝瓷 |
| 内容 / 行业观察 / 文化 | 森林墨 |
| 书评 / 生活方式 / 人文 | 牛皮纸 |
| 设计 / 艺术 / 品牌 | 沙丘 |

---

## 硬规则

- 一份 deck 只用一套主题，不要中途换色
- 不允许用户自定义 hex 值——只从预设中选
- 不允许混搭（例如 ink 取 A 套、paper 取 B 套）
