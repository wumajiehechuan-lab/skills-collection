# 三省六部任务派发工作流程

## 完整流程

```
┌─────────────────────────────────────────────────────────────────┐
│                        皇上旨意                                  │
└─────────────────────────────────────────────────────────────────┘
                              ↓
┌─────────────────────────────────────────────────────────────────┐
│  太子                                                            │
│  1. 判断任务类型（简单/复杂）                                    │
│  2. 创建 JJC 任务                                                  │
│  3. 派发中书省                                                   │
└─────────────────────────────────────────────────────────────────┘
                              ↓ task_dispatch
┌─────────────────────────────────────────────────────────────────┐
│  中书省                                                          │
│  1. 创建子 JJC 任务                                                │
│  2. 起草旨意                                                     │
│  3. 派发门下省（审议）                                           │
└─────────────────────────────────────────────────────────────────┘
                              ↓ task_dispatch
┌─────────────────────────────────────────────────────────────────┐
│  门下省                                                          │
│  1. 审议旨意                                                     │
│  2. 准奏/驳回                                                    │
│  3. 派发尚书省                                                   │
└─────────────────────────────────────────────────────────────────┘
                              ↓ task_dispatch
┌─────────────────────────────────────────────────────────────────┐
│  尚书省                                                          │
│  1. 创建子 JJC 任务                                                │
│  2. 派发工部/六部                                                │
│  3. 监督执行                                                     │
└─────────────────────────────────────────────────────────────────┘
                              ↓ task_dispatch
┌─────────────────────────────────────────────────────────────────┐
│  工部/六部                                                       │
│  1. 创建/更新 JJC 任务                                             │
│  2. 执行任务（opencode / 自行完成）                              │
│  3. 实时更新进展                                                 │
│  4. 回奏尚书省                                                   │
└─────────────────────────────────────────────────────────────────┘
                              ↓ task_dispatch
┌─────────────────────────────────────────────────────────────────┐
│  尚书省 ← 工部回奏                                                │
│  1. 更新看板                                                     │
│  2. 回奏中书省                                                   │
└─────────────────────────────────────────────────────────────────┘
                              ↓ task_dispatch
┌─────────────────────────────────────────────────────────────────┐
│  中书省 ← 尚书省回奏                                              │
│  1. 更新看板                                                     │
│  2. 回奏皇上                                                     │
└─────────────────────────────────────────────────────────────────┘
                              ↓ task_dispatch
┌─────────────────────────────────────────────────────────────────┐
│  皇上 ← 中书省回奏                                                │
│  1. 总控台显示完整流程                                           │
└─────────────────────────────────────────────────────────────────┘
```

---

## 关键节点

### 任务创建节点

| 省部 | 创建任务 | 说明 |
|------|---------|------|
| 太子 | ✅ 必须 | 总任务 ID |
| 中书省 | ✅ 必须 | 子任务 ID |
| 门下省 | ⚠️ 可选 | 审议任务 |
| 尚书省 | ✅ 必须 | 执行任务 ID |
| 工部 | ✅ 必须 | 使用尚书省的任务 ID |

### 看板更新节点

| 操作 | 看板命令 | 频率 |
|------|---------|------|
| 接任务 | `state Doing` | 1 次 |
| 开始执行 | `flow` | 1 次 |
| 进展中 | `progress` | 多次 |
| 完成 | `flow` | 1 次 |

### 回奏节点

| 省部 | 回奏对象 | 说明 |
|------|---------|------|
| 工部 | 尚书省 | 执行成果 |
| 尚书省 | 中书省 | 汇总成果 |
| 中书省 | 皇上 | 最终成果 |

## 数据流向

```
OpenClaw Runtime (sessions)
        ↓
kanban_update.py (创建 JJC 任务)
        ↓
data/tasks_source.json (任务数据)
        ↓
data/live_status.json (实时状态)
        ↓
三省六部总控台 (之意看板 + 省部调度)
```

## 成功标准

使用 task-dispatch 技能后：

1. ✅ **之意看板** — 有完整的 JJC 任务列表
2. ✅ **省部调度** — 有各省部的活动记录
3. ✅ **任务追踪** — 有完整的流转历史
4. ✅ **merit_score** — 各省部有功绩记录
