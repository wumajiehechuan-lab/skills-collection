## 升级注意事项

官方 skill 更新时，若 setup.py 的 SCOPES 列表被覆盖，需要重新合并这 2 行。
重新授权流程（新增/变更 scope 时）：

```bash
GSETUP="python ${HERMES_HOME}/skills/productivity/google-workspace/scripts/setup.py"
$GSETUP --revoke          # 撤销旧 token
$GSETUP --auth-url        # 生成授权 URL（含全部 scope）
$GSETUP --auth-code "URL" # 用户同意后粘贴回调 URL
```
